# Font Files Required

This directory must contain the following font files:

## Montserrat Font Family
- `Montserrat-Regular.ttf` (weight: 400)
- `Montserrat-Medium.ttf` (weight: 500)
- `Montserrat-SemiBold.ttf` (weight: 600)
- `Montserrat-Bold.ttf` (weight: 700)

## Poppins Font Family
- `Poppins-Light.ttf` (weight: 300)
- `Poppins-Regular.ttf` (weight: 400)
- `Poppins-Medium.ttf` (weight: 500)

## How to Download

1. Visit Google Fonts: https://fonts.google.com/
2. Download Montserrat and Poppins font families
3. Extract the .ttf files
4. Place them in this `assets/fonts/` directory
5. Ensure file names match exactly as listed above

## Important

- Fonts are bundled locally - no runtime network fetching
- This prevents DNS failures and unhandled exceptions
- All fonts must be present before building the app
